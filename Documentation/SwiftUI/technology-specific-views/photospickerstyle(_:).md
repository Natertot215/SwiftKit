# photosPickerStyle(_:)

Sets the mode of the Photos picker.

## Declaration

```swift
nonisolated func photosPickerStyle(_ style: PhotosPickerStyle) -> some View

```

### Return Value

A Photos picker that uses the specified mode.

## Parameters

- **mode**: One of the available modes.
