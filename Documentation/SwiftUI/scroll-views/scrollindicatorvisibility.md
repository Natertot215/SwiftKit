# ScrollIndicatorVisibility

The visibility of scroll indicators of a UI element.

## Declaration

```swift
struct ScrollIndicatorVisibility
```

### Overview

Pass a value of this type to the `View/scrollIndicators(_:axes:)` method to specify the preferred scroll indicator visibility of a view hierarchy.
