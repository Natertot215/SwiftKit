# SubmitLabel

A semantic label describing the label of submission within a view hierarchy.

## Declaration

```swift
struct SubmitLabel
```

### Overview

A submit label is a description of a submission action provided to a view hierarchy using the `View/onSubmit(of:_:)` modifier.
