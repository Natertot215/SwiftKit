# ContentHoverEffect

A `CustomHoverEffect` that applies effects to a view on hover using a closure.

## Declaration

```swift
struct ContentHoverEffect<Effect> where Effect : HoverEffectContent
```

### Overview

Use the `CustomHoverEffect/hoverEffect(in:isEnabled:body:)-swift.type.method` method or the `CustomHoverEffect/hoverEffect(in:isEnabled:body:)` or `View/hoverEffect(in:isEnabled:body:)` modifiers to create content effects.

**Conforms To**: `CustomHoverEffect`
