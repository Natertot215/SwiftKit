# ContainerBackgroundPlacement

The placement of a container background.

## Declaration

```swift
struct ContainerBackgroundPlacement
```

### Overview

This method controls where to place a background that you specify with the `View/containerBackground(_:for:)` or `View/containerBackground(for:alignment:content:)` modifier.
