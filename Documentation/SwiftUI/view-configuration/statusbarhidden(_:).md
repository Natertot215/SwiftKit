# statusBarHidden(_:)

Sets the visibility of the status bar.

## Declaration

```swift
nonisolated func statusBarHidden(_ hidden: Bool = true) -> some View

```



## Parameters

- **hidden**: A Boolean value that indicates whether to hide the status bar.
