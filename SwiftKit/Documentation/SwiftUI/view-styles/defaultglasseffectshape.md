# DefaultGlassEffectShape

The default shape applied by glass effects, a capsule.

## Declaration

```swift
struct DefaultGlassEffectShape
```

### Overview

You do not use this type directly. Instead, SwiftUI creates this shape on your behalf as the default parameter of the `View/glassEffect(_:in:)` modifier.
