# PickerStyle

A type that specifies the appearance and interaction of all pickers within a view hierarchy.

## Declaration

```swift
protocol PickerStyle
```







## Relationships

**Conforming Types**: `DefaultPickerStyle`, `InlinePickerStyle`, `MenuPickerStyle`, `NavigationLinkPickerStyle`, `PalettePickerStyle`, `PopUpButtonPickerStyle`, `RadioGroupPickerStyle`, `SegmentedPickerStyle`, `WheelPickerStyle`
