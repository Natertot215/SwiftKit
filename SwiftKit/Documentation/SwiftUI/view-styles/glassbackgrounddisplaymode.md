# GlassBackgroundDisplayMode

The display mode of a glass background.

## Declaration

```swift
enum GlassBackgroundDisplayMode
```

### Overview

Use a value of this type to indicate when to display a glass background that you add to a view using a view modifier like `View/glassBackgroundEffect(displayMode:)`.
