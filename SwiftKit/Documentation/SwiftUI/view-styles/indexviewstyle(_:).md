# indexViewStyle(_:)

Sets the style for the index view within the current environment.

## Declaration

```swift
nonisolated func indexViewStyle<S>(_ style: S) -> some View where S : IndexViewStyle

```



## Parameters

- **style**: The style to apply to this view.
