# animation(_:)

Specifies an animation to perform when the binding value changes.

## Declaration

```swift
func animation(_ animation: Animation? = .default) -> Binding<Value>
```

### Return Value

A new binding.

## Parameters

- **animation**: An animation sequence performed when the binding value changes.
