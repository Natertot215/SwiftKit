# EmptyAnimatableData

An empty type for animatable data.

## Declaration

```swift
@frozen struct EmptyAnimatableData
```

### Overview

This type is suitable for use as the `animatableData` property of types that do not have any animatable properties.

**Conforms To**: `AdditiveArithmetic`, `BitwiseCopyable`, `Copyable`, `Equatable`, `Sendable`, `SendableMetatype`, `VectorArithmetic`
