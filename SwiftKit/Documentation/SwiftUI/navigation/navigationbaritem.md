# NavigationBarItem

A configuration for a navigation bar that represents a view at the top of a navigation stack.

## Declaration

```swift
struct NavigationBarItem
```

### Overview

Use one of the `NavigationBarItem/TitleDisplayMode` values to configure a navigation bar title’s display mode with the `View/navigationBarTitleDisplayMode(_:)` view modifier.
