# Building a document-based app using SwiftData

Code along with the WWDC presenter to transform an app with SwiftData.



### Overview

Learn how to use `Query`, `Bindable`, `View/modelContainer(_:)`, the `EnvironmentValues/modelContext` environment variable, and `DocumentGroup` to integrate with the `SwiftData` framework.

> **NOTE:** This sample code project is associated with WWDC23 session 10154: `https://developer.apple.com/wwdc23/10154/`.







## Availability

- iOS 17.0
- iPadOS 17.0
- Mac Catalyst 17.0
- macOS 14.0
- Xcode 15.0
