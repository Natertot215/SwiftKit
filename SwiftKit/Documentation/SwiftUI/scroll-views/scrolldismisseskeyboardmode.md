# ScrollDismissesKeyboardMode

The ways that scrollable content can interact with the software keyboard.

## Declaration

```swift
struct ScrollDismissesKeyboardMode
```

### Overview

Use this type in a call to the `View/scrollDismissesKeyboard(_:)` modifier to specify the dismissal behavior of scrollable views.
