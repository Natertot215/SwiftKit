# isHoverEffectEnabled

A Boolean value that indicates whether the view associated with this environment allows hover effects to be displayed.

## Declaration

```swift
var isHoverEffectEnabled: Bool { get set }
```

### Discussion

The default value is `true`.







## Availability

- iOS 17.0
- iPadOS 17.0
- Mac Catalyst 17.0
- tvOS 17.0
- visionOS 1.0
