# showSignificantUpdateAcknowledgment

Presents a system interface to inform people about significant app changes and request their acknowledgment.

## Declaration

```swift
var showSignificantUpdateAcknowledgment: SignificantUpdateAction { get }
```

### Discussion

Call this action from a `Button` or `View/onAppear(perform:)` to inform people about significant app changes that require their acknowledgment.







## Availability

- iOS 26.4
- iPadOS 26.4
- Mac Catalyst 26.4
