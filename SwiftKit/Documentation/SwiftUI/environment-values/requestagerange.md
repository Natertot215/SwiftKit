# requestAgeRange

An action that presents a system interface to request a person’s age range.

## Declaration

```swift
var requestAgeRange: DeclaredAgeRangeAction { get }
```

### Discussion

Call this action from a `Button` or `View/onAppear(perform:)` to ask people to share their age range with your app.
