# isScrollEnabled

A Boolean value that indicates whether any scroll views associated with this environment allow scrolling to occur.

## Declaration

```swift
var isScrollEnabled: Bool { get set }
```

### Discussion

The default value is `true`. Use the `View/scrollDisabled(_:)` modifier to configure this property.
