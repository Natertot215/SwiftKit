# ToolbarLabelStyle

The label style of a toolbar.

## Declaration

```swift
struct ToolbarLabelStyle
```

### Overview

Use this type in conjunction with modifiers like `Scene/windowToolbarLabelStyle(fixed:)` and `Scene/windowToolbarLabelStyle(_:)` to customize the appearance of window toolbars managed by SwiftUI.
