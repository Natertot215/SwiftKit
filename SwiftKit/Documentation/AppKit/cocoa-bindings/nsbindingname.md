# NSBindingName

Values that specify a binding for certain methods.

## Declaration

```swift
struct NSBindingName
```

### Discussion

The following values are used to specify a binding to `NSObject-swift.class/bind(_:to:withKeyPath:options:)`, `NSObject-swift.class/infoForBinding(_:)`, `NSObject-swift.class/unbind(_:)` and `NSObject-swift.class/valueClassForBinding(_:)`. See `https://developer.apple.com/library/archive/documentation/Cocoa/Reference/CocoaBindingsRef/CocoaBindingsRef.html#//apple_ref/doc/uid/10000189i` for more information.
