# NSPathComponentCell

A component of a path.

## Declaration

```swift
class NSPathComponentCell
```

### Overview

An `NSPathCell` object manages a collection of `NSPathComponentCell` objects, in conjunction with an `NSPathControl` object, to represent a path.
