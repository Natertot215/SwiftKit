# Additional Writing Directions

Constants that specify additional options when setting the writing direction of attributed strings.



### Overview

You can use the logical `OR` operator to combine these constants with `NSWritingDirection/leftToRight` or `NSWritingDirection/rightToLeft` when used with `NSAttributedString/Key/writingDirection` to specify formatting controls defined by the Unicode Bidirectional Algorithm in Unicode Standard Annex #9.
