# NSAnimation.Progress

The animation progress, as a floating-point number between `0.0` and `1.0`.

## Declaration

```swift
typealias Progress = Float
```

### Discussion

An animation progress value is returned in the `userInfo` dictionary of an `NSAnimation/progressMarkNotification` notification.
