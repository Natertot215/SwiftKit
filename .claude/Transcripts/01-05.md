# Session — 2026-05-01

**Outcome:** SwiftKit project bootstrapped. Phase 0 (Xcode SwiftData template strip) and Phase 2 (URL manifest gather) complete.

## What happened

**Pommora UI shell stalled** after 8+ iterations on sidebar selection styling. Root cause analysis surfaced that the recurring failure was lack of ground-truth visual reference for Apple primitives.

**Decision:** pause Pommora, build SwiftKit instead — a reference library that future Pommora work can point at. Nathan's framing: "lets call it SwiftKit; light dark toggle dark default; everything; ill run many agents; appkit gets its own section."

**Phase 0 — strip Xcode SwiftData template.** Xcode generated SwiftKit with the stock `App with SwiftData` template (Item.swift, ModelContainer, Schema). On macOS 26, attaching `.modelContainer(for: [])` to a `WindowGroup` with no `@Model` types causes silent failure — app launches, no window renders (L-007). Stripped:
- `SwiftKitApp.swift` rewritten without SwiftData (just `@main`, `WindowGroup`, `.windowToolbarStyle(.unified(showsTitle: false))`, `.defaultSize(width: 1100, height: 720)`).
- `ContentView.swift` rewritten to a minimal placeholder.
- `Item.swift` deleted.

**Phase 2 — URL manifest gathering.** Three parallel agents walked Apple's framework topic indexes (using the JSON variant API at `developer.apple.com/tutorials/data/...json` for speed):
- HIG: 170 URLs across Foundations, Patterns, Components, Inputs, Technologies → `Documentation/_links/hig-urls.md`.
- SwiftUI: 1,722 URLs (1,675 unique) across 49 topic groupings → `Documentation/_links/swiftui-urls.md`.
- AppKit: 636 URLs across 30 topic groupings (top-level types/articles only, per-method/per-property NOT recursed — would push to 10,000+) → `Documentation/_links/appkit-urls.md`.
- Consolidated into `Documentation/access-links.md` (2,528 URLs total).

## Decisions locked
- Apple-only doctrine carried verbatim from Pommora.
- Two-column NavigationSplitView with 3-tier sidebar (toggle heading → folder → item).
- Light/dark toggle scoped to detail pane only; sidebar tracks system colorScheme.
- Gallery catalog is a static Swift tree, not data-driven from `Documentation/`.
- AppKit URL list intentionally shallow at framework-topic level (636 URLs).

## Pitfalls observed
- Don't trust agent self-reports — verify by file size + spot-check vs raw fetched JSON.
- WebFetch summarizes by default even with "verbatim" prompts; use `curl` directly for doc capture.
- Apple's HTML is JS-rendered; the JSON variant URL returns structured content reliably.
- 12+ parallel agents burns Anthropic usage limits in ~14 minutes — keep at 2-3 max.
- No Python (Nathan banned it). Bash + curl + jq for capture work.
